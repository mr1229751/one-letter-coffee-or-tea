One letter, one stance: A — coffee. The fuller, more alive, more honest answer for a program that runs on demand. A tiny Node program writes that single character to the entry file, guarding the gate itself: exactly one character, A for coffee or B for tea. The choice was made by criteria critique against the tea stance and four invalid variants.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
